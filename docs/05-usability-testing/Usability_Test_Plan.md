# Usability Test Plan — UG Campus Mobility

## Purpose
Evaluate whether University of Ghana students can successfully use the current clickable prototype to complete the core campus mobility tasks identified from the survey research.

## Participants
- Target: 5 University of Ghana students
- Use anonymous participant IDs: P01, P02, P03, P04, P05
- Do not collect unnecessary personal information

## Test Method
Moderated usability testing using the clickable Figma prototype. Each participant should attempt the same tasks while the facilitator observes without giving unnecessary hints.

## Test Environment
- Device: participant phone or laptop
- Prototype: current UG Campus Mobility Figma prototype
- Setting: quiet campus location or remote screen-share session

## Core Tasks
1. Find Balme Library using the campus map.
2. Check when the next shuttle is expected to arrive.
3. Find the nearest shuttle pickup point.
4. Plan a route from JQB to Balme Library.
5. Check whether there are any current transport delays or service alerts.

## Measures
For each task record:
- Success: Completed / Partially completed / Failed
- Time or rough duration
- Number of obvious errors or wrong turns
- Whether assistance was required
- Main confusion or usability issue observed

## Post-Test Questions
1. How easy was the interface to understand?
2. Which task was easiest?
3. Which task was hardest?
4. Was any label, button or screen confusing?
5. Was any important information missing?
6. What one thing would you improve?

## Evidence
Where appropriate and with participant permission, collect:
- Test-session photos
- Screen recordings or screenshots
- Facilitator notes

## Ethics and Privacy
- Explain that the activity is for an academic HCI project.
- Participation should be voluntary.
- Avoid collecting names unless required by the course.
- Do not upload sensitive participant information to the public repository.

## Completion Rule
Do not write final usability findings until real users have completed the test. Findings must reflect actual observations and participant feedback.
