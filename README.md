# HCI Mobility & Logistics Project

## Overview

This repository contains the research, design, usability evaluation, and final prototype for our Human-Computer Interaction (HCI) semester group project.

## Domain

Mobility and Logistics

## Project Goal

The project follows a user-centred design process to identify usability problems experienced by users of mobility and logistics services and develop an interface solution based on user research.

## Project Process

1. Project Definition
2. User Research
3. Research Analysis
4. Requirements Definition
5. Wireframing
6. High-Fidelity Design
7. Usability Testing
8. Final Prototype
9. Final Report and Presentation

## Repository Structure

- `docs/` — research and documentation
- `design/` — wireframes and interface designs
- `presentation/` — project presentation
- `group-evidence/` — meeting notes and contribution records
