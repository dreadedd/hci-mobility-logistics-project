# Usability Test Tasks — UG Campus Mobility

Give each participant these tasks one at a time. Avoid telling them exactly which button to press.

## Task 1 — Find a Campus Location
You have a lecture near Balme Library and are not sure where it is. Use the prototype to find Balme Library.

**Success condition:** Participant reaches or identifies Balme Library on the campus map.

## Task 2 — Check Shuttle Arrival
You want to know whether it is worth waiting for a shuttle. Find the estimated arrival time of the next available shuttle.

**Success condition:** Participant finds the Live Shuttles screen and identifies an ETA.

## Task 3 — Find a Pickup Point
You want to board a shuttle from the closest available stop. Find the nearest pickup point.

**Success condition:** Participant reaches Pickup Points and identifies the nearest stop.

## Task 4 — Plan a Route
You are at JQB and want to go to Balme Library. Use the prototype to plan a route.

**Success condition:** Participant reaches the route-planning flow and identifies a route from JQB to Balme Library.

## Task 5 — Check Service Alerts
Before leaving, you want to know whether any transport service is delayed. Check the latest service alerts.

**Success condition:** Participant reaches the Service Alerts screen and identifies a current delay/update.

## Facilitator Reminder
Do not coach the participant unless they are completely stuck. Record where they hesitate, choose the wrong control, misunderstand a label, or require assistance.
