# Facilitator Run Sheet — UG Campus Mobility Usability Test

Use this as your live script when running each session. One session = one participant, ~10-15 minutes.

## Before the participant arrives
- [ ] Open the Figma prototype in Play mode, starting on the Home screen
- [ ] Have this Run Sheet and a blank copy of `Usability_Test_Results_Template.md` ready (paper or laptop) to fill in live
- [ ] Assign the next participant ID (P01, P02, P03, P04, P05) — don't ask for their name

## Opening script (read to participant)
> "Thanks for helping out. This is for a university HCI course project — we're testing a prototype for a campus mobility app, not testing you. There are no wrong answers. I'm going to give you a few small tasks, one at a time. Just try to complete them as you naturally would, and talk out loud about what you're thinking or looking for as you go. I won't be able to help much even if you get stuck — that's actually useful information for us. This should take about 10 minutes. Any questions before we start?"

## During each task
- Give ONE task at a time (see `Usability_Test_Tasks.md` for exact wording)
- Start a rough timer when you finish reading the task
- Stay quiet — resist the urge to hint. If they're completely stuck for 60+ seconds, note it as a failure/needs-assistance rather than rescuing them
- Write down, per task:
  - Success / Partial / Failed
  - Rough time taken
  - Where they hesitated, tapped the wrong thing, or looked confused
  - Any comment they made out loud

## Run order
1. Task 1 — Find Balme Library
2. Task 2 — Check shuttle arrival
3. Task 3 — Find nearest pickup point
4. Task 4 — Plan a route (JQB → Balme Library)
5. Task 5 — Check service alerts

## Closing script (read to participant)
> "That's all 5 tasks, thanks! A few quick questions to finish up:"
1. How easy was the interface to understand, overall?
2. Which task felt easiest?
3. Which task felt hardest, or most confusing?
4. Was there any label, button, or screen that confused you?
5. Was there any information you expected to see but didn't find?
6. If you could change one thing, what would it be?

> "That's everything — thank you for your time!"

## Right after the session (don't skip this)
- [ ] Fill in `Usability_Test_Results_Template.md` for this participant while it's fresh — don't wait until after all 5 sessions
- [ ] If you took a photo/screen recording (with permission), save it to `docs/05-usability-testing/evidence/`
- [ ] Reset the prototype back to the Home screen for the next participant

## After all 5 sessions
- Look across all 5 result sheets for patterns: which task had the most failures? What confused more than one person?
- Fill in `Usability_Findings_Template.md` with the real, aggregated findings — this is what feeds the final report
